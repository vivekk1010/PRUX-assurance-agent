# Glossary

| Term | Meaning |
|---|---|
| Blog Notes | The StageUI application under test |
| Post / Blog | A plain-text note with title, content, tags and metadata |
| My Blogs | The list page at `/blogs` showing the logged-in user's posts |
| Metadata | Author, published date, tags, word count, reading time |
| Reading time | Estimated minutes to read a post (BR-META-02) |
| StageUI | The isolated pre-production environment the agent tests; never production |
| Approved variance | A design difference product has accepted (e.g. button copy); not a defect |
| AC | Acceptance criterion, identified as `AC-NN` within a story |
